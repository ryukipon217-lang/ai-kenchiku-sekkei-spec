## 1. 調査範囲と方法

### 1.1 目的

指示文4.1（連合商品台帳の四層）、C5（家具、設備、建材の検索と推薦）、C7（独自家具の3D生成）、9.5（推薦の内部判断）、9.6（商品情報の更新と消失）の記述を基準に、2026-09-15時点の公式情報で次を確認した。

- 正規3D情報の提供形式（IFC、Revit、ArchiCAD、GLB、DWG等）
- 利用許諾の条件（設計用途の可否、商用利用、改変、再配布、第三者製品への組込、自動収集）
- APIの有無
- 価格や在庫の取得手段

### 1.3 方法と制約

- 公開頁の読み取りのみ。申込、資料請求、問合せ、会員登録、ログインは行っていない。会員限定頁の内容は【未確認】とした
- 1対象あたり WebFetch 最大3回、WebSearch 最大2回。上限内で取得できなかった頁は「取得失敗」と理由を記録した
- 取得方法を区別する。「直接取得」は頁本文を取得した事項、「検索経由」は検索結果に表示された公式頁の要約から得た事項。検索経由の事項は出典が公式頁でも本文を直接確認していないため、確度が一段低い【事実】として扱う
- 第三者報道や第三者サイトのみで確認した事項は【未確認】とした
- 画像、写真、商品3D、間取り図の複製や転載は行っていない。文章での要約に限る
- 各社の主張（処理時間、導入数、効果）は独立試験ではなく公開主張として扱う

## 章要約

商品情報基盤と生成3Dの提供状況を2026-09-15時点の公式頁で確認した。BIMobject と Archiproducts は設計者向けの無料配布が中心で、規約は第三者製品への組込、商業的利用、自動収集を禁止しているため、本製品の「正規商品」層は製造元との直接許諾か基盤との事業契約が前提になる。建材では LIXIL（約880種）、TOTO（GDL、Revit ファミリ）、YKK AP（RFA、GSM、LCF）、Daikin（Revit、Rebro、IFC。住宅用ルームエアコン含む）が BIM を提供するが、許諾は「設計と提案業務」「社内利用」に限る文言が多い。Panasonic の住宅設備、Cleanup、Takara Standard は 2D 図面と画像が中心で、3D と BIM は確認できなかった。家具では飛騨産業（DWG、3DS、STP）と CONDE HOUSE（DXF、DWG、3DS）が法人審査付きで 3D を提供し、カリモクは RoomieTale へ有償提供した前例がある。IKEA、ニトリ、MASTERWAL、無印良品は外部提供や API を確認できなかった。生成3Dは Meshy（API v2、meshy-7、preview と refine、target_polycount、PBR、glb 等7形式）と Tripo（H3.1、P1.0、1クレジット0.01米ドル）で指示文C7の形式要件を満たせるが、実寸と原点は保証されず、権利はプランと参照画像に依存する。四層のうち公式情報参照層と分類別一般品層が初期の主力になる。
