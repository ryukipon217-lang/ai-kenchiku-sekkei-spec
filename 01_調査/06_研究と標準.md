## 章要約

図面理解研究4件と標準・工程枠組み10件を公式頁で再確認した。研究では、CubiCasa5K（5000件、80超分類、試験mIoU室57.5%/アイコン55.7%、多角形化後はさらに低下）、FloorPlanCAD（学習10,161＋試験5,502のベクトル図、PQ 0.561、窓PQ 0.577、CC BY-NC 4.0）、FloorplanVLM（Beike、外壁IoU 0.9252、開口F1 0.7333、非直交壁で低下、座標は整数格子）、HouseCrafter（間取り条件の拡散生成、寸法と意味を持たない派生出力）を確認し、開口の認識精度が最も弱く利用者確認必須とすべきこと、写実生成を建築モデルと呼ばない原則の根拠を得た。標準では IFC 4.3.2.0（ISO 16739-1:2024）、IDS 1.0（2024年6月）、BCF 3.0（2021年6月）、bSDD の辞書構造（Preview/Active、SPDX ライセンス）、glTF 2.0（ISO/IEC 12113:2022）、web-ifc 0.77（MPL-2.0、対応要素未文書化）を確認した。RIBA Plan of Work 2020 の八段階と9横断課題、AIA の十観点、国土交通省の標準ワークフロー第3版とBIM図面審査基準（2026年3月）、UK BIM Framework の IMI Framework への改称（2025年5月）を確認し、本製品七段階との対応表を示した。buildingSMART 公式頁は403で直接取得できず、GitHub 公式リポジトリと検索結果で補完した。

## 用語追加提案

| 用語 | 定義 | 理由 |
|---|---|---|
| 情報要求適合表 | 段階門ごとに必要な要素、属性、値域、状態を列挙し、IDS 1.0 の specification（applicability と requirements）として機械検査できる形にした表 | 指示文C15の必須成果であり、IDS との対応を明示するため |
| 責任表 | 要素または判断ごとに主担当領域を一つ、影響先領域を複数、確認者を定めた表。RIBA Toolbox の Design Responsibility Matrix に相当 | 段階4の必須成果であり、「一つの判断に主担当領域を一つ」の原則を表現するため |
| 横断課題 | 段階をまたいで継続的に検討する課題（費用、防火、健康安全、包摂、計画、使用準備、調達、持続可能性、保全）。RIBA の Project Strategies に相当 | 段階門の検討漏れ防止の枠として全章で同じ語を使うため |
| 妥当性率 | 図面認識の出力が、壁の閉合、室と壁の参照整合など構造として成立している割合。FloorplanVLM の validity rate に相当 | 幾何精度（IoU、F1）と分けて、V2幾何検証へ進める前提条件を計測するため |
| 多角形化後精度 | 画素または線分の認識結果を、寸法と関係を持つ要素（多角形）に変換した後の精度。CubiCasa5K の polygonized 指標に相当 | 生の分割精度より低くなることが研究で示されており、要素としての精度を別に計測するため |
| 派生出力 | 正規建物情報から一方向に生成され、建物情報へ書き戻さない出力（写実画像、glTF、印刷図面等） | 写実生成物を建築モデルと呼ばない原則を用語で担保するため |
