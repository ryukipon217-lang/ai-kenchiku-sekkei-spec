## 1. RC-25 旧耐震の着工年閾値（第12章 DV-ST-10、第21章 第2.4節 (a)、U-21-014、JR-095 の年の閾値）

### 1.1 問い

DV-ST-10 の「全構造 1981-05-31 以前の着工、木造は 2000-05-31 以前の着工も対象」は、どの法令または公的文書のどの文言に基づき、「着工」で判定してよいか。

## 2. RC-27 大規模の修繕と大規模の模様替の「過半」の判定式（第21章 第2.4節 (b)、AC-C14-001-04、U-21-012、第18章 第4.2節、JR-095 の過半、JR-099）

### 2.1 問い

「過半」は主要構造部の種類ごとに何（面積、本数、水平投影面積、個数）で数えるか。主要構造部に当たる壁はどれか。撤去、補強、新設、移設はどう数えるか。新2号建築物の改修で確認申請を要する範囲と、既存不適格の扱いはどうか。

## 用語追加提案

| 用語 | 定義 | 理由 |
|---|---|---|
| 主要構造部 | 建築基準法 第2条第5号の壁、柱、床、はり、屋根又は階段（構造上重要でない間仕切壁、最下階の床、小ばり、局部的な小階段等を除く）。防火上の観点の概念で、主要構造部の壁は外壁、鉛直荷重を負担する間仕切壁、防火・避難上の区画をする間仕切壁 | 確認申請の要否候補の判定に使い、構造耐力上主要な部分と混同しないため |
| 構造耐力上主要な部分 | 住宅の基礎、基礎ぐい、壁、柱、小屋組、土台、斜材、床版、屋根版又は横架材で、自重、積載荷重、積雪、風圧、土圧、水圧、地震等を支えるもの（品確法施行令 第5条第1項） | 既存住宅状況調査と主要構造部を区別するため |
| 過半（大規模の修繕・模様替） | 主要構造部の種類ごとに、改修する部分の量が工事前の総量の 1/2 を超えること。壁は面積、柱と梁は本数、床と屋根は水平投影面積、階段は階ごとの数で数える | 第21章の判定式の語を一つにするため |
| 耐震不明建築物 | 耐震改修促進法 第5条第3項第1号の、地震に対する安全性が明らかでない建築物。施行令第3条で昭和56年5月31日以前に新築の工事に着手したもの（後の工事で検査済証を受けたものを除く） | DV-ST-10 の値の根拠の語として |
| 劣化事象等 | 既存住宅状況調査方法基準で、劣化事象その他不具合である事象。部位ごとに有無を調べ、調べられない部位は「調査できない」とする | 調査記録の受入の三値の根拠の語として |
| 直角路 | 通路から直角に曲がって別の通路へ進む経路。障害者の居住にも対応した住宅の設計ハンドブックは、一方の有効幅員 800mm 以上なら他方 850mm 以上とする | JR-091 の判定項目の語として |
| 内眼角高 | 床から内眼角（目頭）までの高さ。産総研の人体寸法データベースで眼高に当たる計測項目 | DV-FN-03 の換算の根拠の語として |
| BELS 評価書 | 住宅性能評価・表示協会に登録した BELS 評価機関が発行する、省エネ性能の第三者評価の文書。ZEH 等の区分を記載できる | ZEH の表示を許す EL-3RD の文書の語として |
| 適合判定通知書 | 建築物省エネ法 第11条、第12条による建築物エネルギー消費性能適合性判定の結果を記載した通知書 | EL-LAW の文書の語として |
