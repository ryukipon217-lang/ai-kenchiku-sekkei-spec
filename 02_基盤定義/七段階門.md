## 0. 総則

| 規則 | 内容 | 区分 |
|---|---|---|
| 段階と門 | 案件は G0〜G6 の七段階を持つ。段階の完了条件を満たした時点が門であり、`G2→G3` のように書く。門を通過しない限り、次段階の必須成果を「完了」と表示せず、次段階に対応する信頼状態を表示しない | 【推定】 |
| 各段階の定義項目 | 開始条件、必要情報、主要判断（主担当領域付き）、必須成果、確認者、完了条件、進行禁止条件、実装優先（P0/P1/P2）、許される信頼状態 | 【推定】 |
| 進行禁止条件 | 該当する問題は重大度 SEV-0 とし、解決以外に解除方法はない（例外承認で越えられない。誤警告の却下は第4節の例外）。段階門画面（S-13）に理由と解除に必要な成果を表示する | 【仮定】 |
| 完了条件の例外 | SEV-1 の未解決問題は、確認者による例外承認（理由、承認者、期限）があれば持ち越せる。SEV-2、SEV-3 は担当と期限を付けて持ち越せる。P0 で資格者のいない案件では、第6章 第1.1節 規則6 (b) の対象の SEV-1 を担当（RL-OWN）と期限（G4 の門）を付けて G3 から持ち越し、G4 の欠落の自動記録 (i)（第6章 第2.5節）として受取側へ渡す。規則6 (b) の対象は次の五つ: 地盤仮定（第13章 第2.3節 項目9）、擁壁と地盤調査（第18章 第2.1節 項目9、10）、重い設備の載荷（第13章 第2.3節 項目7）、P0 対象外の構法による構造注意の判定不能（既存構造が未定の改装を含む。既存壁の撤去と移動を含む改装案は除く）、不足調査に伴う A02 の SEV-1（第18章 第2.1節 項目1 測量、項目2 道路種別の行政照会）。期限の意味: 受取側の RL-CHK が欠落 (i) を例外承認（scopeKind=例外、理由、期限）した時点で、持ち越した問題を IS-EXC（approverRef=受取側の RL-CHK）にし、期限を受取側の再設計範囲の期日にする。例外承認がない間は I-00-123 で G4 を通過させず、発行もしない（修正計画 第0.3節。v1.3、JR-014） | 【仮定】 |
| 戻り | 後の段階の変更が前の段階の成果に影響した場合、影響範囲の承認だけを自動失効させ、案件全体を前段階へ戻さない。ただし段階の完了条件を再び満たすまで、その段階の門は「再確認中」と表示する | 【仮定】 |
| 初期公開 | P0 は G0〜G3 と G4 への最小引継ぎを完成させる。G5、G6 は P2 だが、識別子、版、出典、責任、状態は初期から保持する（指示文10.4、G） | 【推定】 |
| 信頼状態との対応 | 各段階で表示できる最大の信頼状態を第2節に定める。段階の門を通過していない案は、その段階に対応する信頼状態へ昇格できない | 【推定】 |
| 交差表の位置付け | 第3節の交差表は主担当領域の割当表であり、北極星指標 M-N-01 の分母（源1）ではない。源1 の正本は第6章 第2.1〜2.7節の主要判断（第2章 第4.3節の雛形）であり、交差表の「源1 対象」列で一対一に対応付ける。対応しない「有」の交差は「（源1対象外）」と記す（v1.2、JM-001） | 【推定】 |

## 4. 進行禁止条件の運用

| 規則 | 内容 | 区分 |
|---|---|---|
| 検出 | 進行禁止条件は決定的検査で検出し、該当時は問題を SEV-0 で登録する。言語模型の判断だけで解除しない | 【仮定】 |
| 表示 | 段階門画面（S-13）に、段階、条件、該当する問題、解除に必要な成果、担当を表示する。信頼状態の表示は現段階のまま据え置く | 【推定】 |
| 解除 | 該当する問題が解決（解決証拠付き）された時だけ解除する。例外承認では解除できない。誤警告の却下（資格を登録した RL-CHK が理由を付けて IS-REJECTED にする。P0 は本人申告〔未照合〕の資格を含み、却下に「資格未照合（本人申告）」を表示する。P1 は照合済みの資格に限る。v1.3、JR-012）は解除の例外とし、解決ではなく Gate.blockingIssueRefs から除いて M-G-09（誤警告率）に計上し、監査記録に残す。P0 で資格を登録した RL-CHK が未登録の案件では却下できず、元に戻す変更だけが復旧経路になる（v1.2、JM-033、JM-023）。却下の再登録を抑止する単位（規則の識別子と版、anchor、入力の指紋 E-REQ-003.rejectionFingerprint）と、再判定で再登録する条件（(a) 余裕量が却下時より小さくなった、(b) 別の条項が負になった、(c) 法令版が更新された）は第6章 第8.1節「解除」が正本（JR-023。v1.5 で参照を追加） | 【仮定】 |

## 章要約

本章は指示文C15と10.4の七段階 G0〜G6 を、開始条件、必要情報、項番付きの主要判断（主担当領域付き）、必須成果、確認者、完了条件、進行禁止条件（I-00-101〜133 と第6章の I-06-001〜007。すべて SEV-0）、実装優先（G0〜G4 は P0、G5 と G6 は P2）、許される信頼状態で定義し、門を通過しない案は次の信頼状態へ昇格できないとした。7×12 の交差表は主要判断の有無（有、無、影響先）、必須成果、源1 対象、確認者（P0、P1）を持つ主担当の割当表で、北極星の分母ではない。進行禁止条件は決定的検査で検出し解決だけで解除し、発行と引継ぎ一式の生成は未解決の進行禁止条件がない案に限る。完了条件と交差表の正本は第6章で、本章は写しである。v1.3（二回目の修正）で G0〜G4 の完了条件を第6章の番号に同期し（G2 は (1)〜(10)）、G3 完了条件(2)の統一文、規則6 (b) の五つの対象、I-06-006 の判定段階、EL-LAW の到達条件、影響先の交差と源1 対象外の交差を反映した。
