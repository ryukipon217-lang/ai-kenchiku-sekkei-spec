## 0. 総則

| 規則 | 内容 | 区分 |
|---|---|---|
| 文字 | 識別子は半角の英大文字、数字、ハイフン「-」、ピリオド「.」だけで構成する。全角文字、空白、下線は使わない | 【仮定】 |
| 不変性 | 一度付与した識別子は変更も再利用もしない。対象が消える場合は「廃止」とし、台帳に残す（第6節） | 【仮定】 |
| 変わり得る属性を含めない | 識別子に含めてよいのは付与後に変わらない区分だけ（機能区分C01〜C15、画面番号、指標区分、試験種別、定義した章番号）。主担当領域、優先度、重大度、状態のように変わり得るものは属性として持ち、識別子に含めない | 【仮定】 |
| 一対象一識別子 | 章をまたいで同じ対象には同じ識別子を使う。同じ対象に別の識別子を付けた場合は整合検査で重複として扱う | 【仮定】 |
| 仕様識別子と実行時識別子 | 仕様書で定義する対象（機能、実体定義、画面、指標、試験、API、非機能、受入条件、未決、審査指摘）は仕様識別子。運用時に生成される個体（案件、要求、問題、判断、要素、承認）は実行時識別子。仕様書内で個体を例示する場合は「例示識別子」（第3節）を使う | 【仮定】 |
| 版 | 識別子の後に半角空白を置き `v主.副` を付ける（例: `F-C02-003 v1.0`）。主番号は互換性のない変更（目的、入出力、受入条件の変更）、副番号は互換の追記や字句修正で上げる。初版は v1.0 | 【仮定】 |
| 台帳 | 全識別子は `04_必須表/識別子台帳.md` に集約し、整合検査（重複ゼロ、未割当ゼロ）を行う。台帳の作成は04_必須表担当へ依頼する | 【仮定】 |
| 例示は定義ではない | 本章の第1節「例」列、第2節〜第6節の「例」と例示に現れる識別子は書式の例示であり、定義ではない。本章が定義する識別子は「本章で定義した識別子一覧」に載せたもの（S-01〜S-14、M-N-01、M-G-01〜M-G-07、G0〜G6、A01〜A12、V0〜V3、状態符号の体系、P0〜P2）に限る。それ以外の識別子の名称と定義の正本は定義した章（台帳の正本列）であり、例と食い違う場合は正本に従う（v1.2、JM-193） | 【推定】 |

## 4. 版の付け方

| 規則 | 内容 |
|---|---|
| 書式 | `識別子 v主.副`（例: `F-C02-003 v1.0`、`用語集 v1.0`）。文書全体にも同じ書式で版を付ける |
| 初版 | v1.0。初稿審査前の草稿は v0.x |
| 主番号を上げる変更 | 目的、利用者、入出力、権限、受入条件の変更。段階門の条件変更。状態符号の追加や意味変更 |
| 副番号を上げる変更 | 字句修正、例の追加、根拠区分の更新、関連識別子の追記 |
| 版の参照 | 他章から参照する場合は版を省略してよい。省略時は台帳の最新版を指す。特定版に依存する場合だけ版を書く |
| 状態符号の版 | VS-、EL- 等の符号集合そのものに版を付ける（例: `VS v1.0`）。符号を追加した場合は主番号を上げ、全章の影響先を台帳で追う |

## 5. 廃止時の扱い

| 規則 | 内容 |
|---|---|
| 廃止の宣言 | 台帳の該当行に「廃止 v{版} 理由 後継識別子」を記す。識別子は削除せず再利用しない |

## 章要約

本章は全章が使う識別子体系を定めた。接頭辞は機能 F-（C01〜C15）、情報実体 E-（11群）、画面 S-（14画面を固定）、指標 M-（北極星と防護指標を固定）、試験 T-、問題 I-、判断 D-、要求 R-（例示は章2桁、実行時は案件 PJ- を含む）、段階 G0〜G6、領域 A01〜A12、信頼状態 V0〜V3、状態符号 VS-/EL-/CS-/PT-/RS-/PR-/CDE-/RL-/RP-/SEV-/IS-/AS-/SUP-、優先 P0〜P2、未決 U-、審査 J-/JR-、API AP-、非機能 N-、受入条件 AC-、出典 SRC-、再確認項目 RC-、差分 DIF-、既定値 DV-、非対象事項 NS-。識別子は不変で再利用せず、変わり得る属性を含めず、版は `v主.副`、廃止は台帳に残して後継を記す。整合検査は重複、未割当、参照切れのゼロ、主担当一意、因果ひも付け、受入条件と試験の存在を見る。v1.2 で例示の除外を定め、v1.3 で SRC-、RC-、DIF-、DV-、NS- と 01_調査の章符号 80〜87 を登録した（88 は 2026-10-07 追記）。
