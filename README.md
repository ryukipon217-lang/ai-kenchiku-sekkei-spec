# AI建築設計 製品仕様書（日本の戸建住宅における設計意思決定基盤）

建築学部の学生がモデル作成や図面作成を学ぶための補助教材として公開している、架空の Web 製品「AI建築設計」の製品仕様書一式です。営利目的の利用は想定していません。

- 最終報告（Web ページ）: https://ryukipon217-lang.github.io/ai-kenchiku-sekkei-spec/
- 最終報告（Markdown）: [06_最終報告/最終報告.md](06_最終報告/最終報告.md)
- 全文を一つにまとめた統合版: [AI建築設計_製品仕様書_統合版.md](AI建築設計_製品仕様書_統合版.md)（約 309 万字。GitHub の画面では大きすぎて表示されないことがあるため、ダウンロードして読んでください）

## どんな製品の仕様書か

日本の戸建住宅を検討する家族と設計の専門家のあいだで、希望、図面、敷地、構造、外皮、設備、費用、商品、承認を一つの建物情報で結び、重要な設計判断の根拠と合意と引継ぎを支える「設計意思決定基盤」の仕様です。三次元の画像を作ることそのものではなく、承認前の案を施工可能と表示しないこと、根拠のある判断を残すことを中心に置いています。

最終判定は「P0（初期公開）の製品仕様として条件付き適合。公開可とは結論しない。施工可能な設計を自動完成する製品としては未適合」です。試験は未実施で、閾値と件数は初期仮説です。

## 読む順序

1. 最終報告（上の Web ページ）で全体の判定と経過をつかむ
2. `06_最終報告/正本の節の索引.md` で、役割ごとに読む章と節を選ぶ
3. `03_仕様書/01_経営向け要約.md` と `03_仕様書/02_理想の完成像_非対象_目的から成果への因果_指標の木.md` で製品の目的をつかむ
4. 図面と 3D に関心がある場合は第11章（図面読解、現況差分、3D 構築）、第12章（正規建物情報）、第13章（空間、構造、外皮、設備の調整）、第15章（画面）へ進む
5. 識別子の意味は `02_基盤定義/用語集.md` と `02_基盤定義/識別子規則.md` で確かめる
